# Source documents

Download these two official PDFs into this folder, then run `python build_corpus.py`:

| File name | Document | Public copy |
|---|---|---|
| `labor-code-2022.pdf` | Labor Code of the Philippines, DOLE 2022 renumbered edition (136 pages) | [ILO NATLEX](https://natlex.ilo.org/dyn/natlex2/natlex2/files/download/15242/PHL15242%202022.pdf) |
| `wsmb-handbook-2024.pdf` | DOLE Handbook on Workers' Statutory Monetary Benefits, 2024 edition (81 pages) | [DOLE NWPC](https://nwpc.dole.gov.ph/wp-content/uploads/2024/11/Workers-Statutory-Monetary-Benefits-Handbook-2024-Edition.pdf) |

Both are DOLE publications distributed free of charge ("NOT FOR SALE"); their
copyright notices restrict commercial reproduction only. The PDFs are not committed; the extracted
text in `data/corpus.json` is.
